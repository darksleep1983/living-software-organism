# Design origin

The living-ship idea in *LEXX* was a conceptual spark and metaphor for thinking about a software project as a durable organism. Living Software Organism is an original software architecture. No affiliation, adaptation, runtime dependency, or copied fictional intellectual property is implied.

GRAPH was the first private reference implementation and dogfood environment; this extraction has no runtime dependency on it.

The software principle is independent of that inspiration: project identity and continuity belong to the project, while AI models, providers, and executors are replaceable temporary organs.
